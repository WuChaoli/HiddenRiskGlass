## 问题与建议

### 已知问题

1. **相机初始化问题**
   - HiddenRiskProbeActivity在真机上显示"样图拍摄超时"
   - 原因: 需要真实相机环境，模拟器/测试环境相机链路不完整
   - 建议: 在完整集成测试中验证相机功能

2. **入口Activity配置**
   - 当前入口是HiddenRiskProbeActivity（相机巡检）
   - 建议: 根据流程图，应该将InspectionModeActivity（模式选择）设为入口

### 改进建议

1. **流程完整性**
   - 建议将应用入口从HiddenRiskProbeActivity改为InspectionModeActivity
   - 实现Activity之间的流程跳转逻辑

2. **相机功能验证**
   - 需要在真机环境中验证完整的相机拍照和AI推理流程
   - 建议添加更多错误处理和重试机制
