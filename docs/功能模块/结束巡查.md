## 1. 功能目标

- 为隐患识别、设备指引、隐患录入三条正式能力提供统一结束页。
- 展示当前巡检汇总缩略图和标题。
- 根据来源首页执行取消返回或确认结束上报。

## 2. 功能边界

- 本模块负责：
  - 渲染结束页摘要。
  - 根据来源页决定取消返回目标。
  - 触发结束巡检后台上报并退出任务。
- 本模块不负责：
  - 单个功能页内部的保存逻辑。
  - 企业二维码和对象信息准备。
  - Wi-Fi 或扫码链路。
- 本模块依赖：
  - [公共能力/会话与生命周期.md](../公共能力/会话与生命周期.md)
  - `InspectionWorkflowSession`
  - `InspectionBackgroundUploadQueue`
  - `InspectionBackgroundUploadService`

## 3. 用户旅程 / 主流程

1. 用户在隐患识别、设备指引或隐患录入中触发结束任务。
2. 页面进入 `InspectionEndReportActivity`。
3. 页面读取 `InspectionWorkflowSession` 中已保存的缩略图和隐患数量。
4. 用户确认时，如果企业巡检链路开启且企业信息齐全，则入队后台结束上报。
5. 上报任务提交后，页面重置工作流会话并退出应用任务。
6. 用户取消时，页面根据 `InspectionEndReportReturnDestination` 返回对应来源首页。

## 5. 页面详情

## `InspectionEndReportActivity`

### 页面职责

- 展示巡检结束摘要和缩略图。
- 接收来源首页标记。
- 处理确认结束和取消返回。

### 进入条件

- `AiInspectionActivity`、`DeviceGuideActivity` 或 `HazardRecordActivity` 触发结束。

### 退出路径

- `Confirm`：结束巡检后台上报后退出应用任务。
- `Cancel`：返回来源首页。

### 页面状态

- `SUMMARY`

### 关键 UI 元素

- 缩略图网格。
- 隐患数量 / 标题文本。
- 操作提示。
- 状态栏。

### 可见性约束

- `operationGuideEnd` 和 `bottomPromptEnd` 默认隐藏。
- 缩略图为空时隐藏缩略图滚动区。

## 8. 后端与数据链路

## 链路 A：结束页摘要构建

- 接口用途：从工作流会话中构建结束页缩略图和数量摘要。
- 触发时机：页面 `onCreate()`。
- 调用入口代码：
  - `InspectionWorkflowSession.buildEndReportThumbnails()`
  - `InspectionWorkflowSession.buildEndReportHazardCount()`
- 请求来源数据：
  - 已保存的 `SavedHazardRecord`
- 成功后的页面 / 会话更新：
  - 渲染缩略图网格和标题文案
- 失败后的降级、回退、提示：
  - 无缩略图时隐藏缩略图区
- 日志锚点：
  - `sessionMemory reason=buildEndReportThumbnails`

## 链路 B：结束巡检后台上报

- 接口用途：在用户确认结束时，把当前巡检结束事件入队后台上报。
- 触发时机：结束页 `Confirm`。
- 调用入口代码：
  - `InspectionEndReportActivity.submitFinishInspectionInBackground()`
  - `InspectionBackgroundUploadQueue.enqueueFinishInspection(...)`
  - `InspectionBackgroundUploadService.start(...)`
- 请求来源数据：
  - `InspectionWorkflowSession.enterpriseQrPayload`
  - `InspectionWorkflowSession.resolveFinishSessionId()`
- 关键请求字段：
  - `baseUrl`
  - `authCode`
  - `objectId`
  - `userId`
  - `customParam`
  - `sessionId`
- 成功后的页面 / 会话更新：
  - 入队成功后退出任务
  - `InspectionWorkflowSession.resetAll()`
- 失败后的降级、回退、提示：
  - 若企业巡检未启用或缺少企业信息，则跳过上传直接退出
- 日志锚点：
  - `skip finish background upload: missing enterprise payload`

## 9. 会话与本地状态

- `InspectionEndReportReturnDestination`
  - 决定取消时回到哪个首页。
- `InspectionWorkflowSession.buildEndReportThumbnails()`
  - 提供缩略图。
- `InspectionWorkflowSession.buildEndReportHazardCount()`
  - 提供摘要数量。
- `InspectionWorkflowSession.resolveFinishSessionId()`
  - 提供结束上报使用的会话 ID。

## 11. 异常与降级分支

- 企业巡检未启用：
  - 确认后直接退出，不走后台上传。
- 企业二维码上下文缺失：
  - 确认后直接退出。
  - 开发检查 `enterpriseQrPayload`。
- 无缩略图：
  - 页面仍可结束，只是不展示图集。
- 来源页标记异常：
  - 由 `InspectionEndReportReturnDestination.fromIntentValue(...)` 回落默认值。
