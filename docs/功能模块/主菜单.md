# 主菜单

本文档是 `docs/功能模块/主菜单.md` 的单一正文真相源，收敛主菜单的选项、输入映射和功能分发规则，并对齐当前代码与正式主链。

## 1. 功能目标

- 作为正式巡检主链的功能分发页，向用户提供隐患识别、设备指引、隐患录入三个入口。
- 对需要巡检初始化状态的功能执行会话门槛校验。

## 2. 功能边界

- 本模块负责：
  - 展示三个正式功能入口。
  - 维护当前选中项。
  - 把触控和语音映射为对应功能跳转。
  - 对隐患识别和设备指引执行 `InspectionSession.isInitialized` 检查。
- 本模块不负责：
  - 执行功能内部逻辑。
  - 管理后端接口。
  - 管理企业信息上下文。
- 本模块依赖：
  - [公共能力/统一输入.md](../公共能力/统一输入.md)
  - [公共能力/页面导航分层.md](../公共能力/页面导航分层.md)
  - `InspectionSession`
  - `InspectionLoadingActivity`

## 3. 用户旅程 / 主流程

1. 用户在企业信息确认页点击确认后进入 `AiInspectionMenuActivity`。
2. 页面默认选中第一项“隐患分析”。
3. 用户通过前滑 / 后滑切换选中项。
4. 用户单击确认当前选中项，或直接说出目标功能名。
5. 若目标是隐患识别或设备指引，页面先判断 `InspectionSession.isInitialized`。
6. 若已初始化则直接进入目标功能首页；否则先进入 `InspectionLoadingActivity`。
7. 若目标是隐患录入，则直接进入 `HazardRecordActivity`。

## 5. 页面详情

## `AiInspectionMenuActivity`

### 页面职责

- 展示三个正式能力入口。
- 维护当前菜单选中态。
- 分发到目标功能首页。

### 进入条件

- `EnterpriseInfoActivity` 确认。
- 或测试时直接启动。

### 退出路径

- “隐患分析”进入 `AiInspectionActivity` 或 `InspectionLoadingActivity`。
- “设备指引”进入 `DeviceGuideActivity` 或 `InspectionLoadingActivity`。
- “隐患录入”直接进入 `HazardRecordActivity`。

### 页面状态

- `SELECTING`

### 关键 UI 元素

- 三张菜单卡片。
- 当前选中卡片高亮。
- 底部操作提示。
- 状态栏。

### 可见性约束

- 当前页没有结果态或子态。
- 只通过 `selectedIndex` 切换高亮背景，不切换布局结构。

### 页面截图

- 本轮未保留 `AiInspectionMenuActivity` 真机截图。
- 原因：该页是非导出页，必须经 `EnterpriseInfoActivity` 确认后进入；当前自动化未稳定完成这段前序链路。
- 补采要求：必须从企业信息确认页真实进入，不接受历史调试页或相邻功能页代替图。

## 6. 交互定义

### 触控指令

| 动作 | 触发器 | 生效状态 | 注册位置 | 结果 |
| --- | --- | --- | --- | --- |
| `Previous` | 后滑 | 全状态 | `AiInspectionMenuActivity.buildInputActions()` | 选中项向前移动，最小到第一项 |
| `Next` | 前滑 | 全状态 | `AiInspectionMenuActivity.buildInputActions()` | 选中项向后移动，最大到最后一项 |
| `Confirm` | 单击 | 全状态 | `AiInspectionMenuActivity.buildInputActions()` | 触发当前选中项 |

## 7. 页面跳转与路由规则

| 来源页面 | 条件 / 动作 | 目标页面 | 失败 / 回退 |
| --- | --- | --- | --- |
| `EnterpriseInfoActivity` | `Confirm` | `AiInspectionMenuActivity` | 无 |
| `AiInspectionMenuActivity` | 选择“隐患分析”且 `InspectionSession.isInitialized == true` | `AiInspectionActivity` | 无 |
| `AiInspectionMenuActivity` | 选择“隐患分析”且 `InspectionSession.isInitialized == false` | `InspectionLoadingActivity` | 加载后继续正式链路 |
| `AiInspectionMenuActivity` | 选择“设备指引”且 `InspectionSession.isInitialized == true` | `DeviceGuideActivity` | 无 |
| `AiInspectionMenuActivity` | 选择“设备指引”且 `InspectionSession.isInitialized == false` | `InspectionLoadingActivity` | 通过 `EXTRA_NEXT_HOME_ACTIVITY` 指向 `DeviceGuideActivity` |
| `AiInspectionMenuActivity` | 选择“隐患录入” | `HazardRecordActivity` | 无 |

## 8. 后端与数据链路

## 链路 A：菜单分发

- 接口用途：本模块不直接请求后端，只做功能分发。
- 触发时机：用户单击确认或说出目标功能名称时。
- 调用入口代码：
  - `AiInspectionMenuActivity.onItemConfirmed(...)`
  - `AiInspectionMenuActivity.startHazardAnalysis()`
  - `AiInspectionMenuActivity.startDeviceGuide()`
- 请求来源数据：
  - `selectedIndex`
  - `InspectionSession.isInitialized`
- 成功后的页面 / 会话更新：
  - 按条件跳转目标功能页。
- 失败后的降级、回退、提示：
  - 本模块无独立失败页；初始化不足时统一回退到 `InspectionLoadingActivity`。
- 日志锚点：
  - 本页未额外记录网络或服务日志，主要依靠路由结果与前台 Activity 验证。

## 9. 会话与本地状态

- `selectedIndex`
  - 当前菜单选中项。
- `InspectionSession.isInitialized`
  - 决定隐患识别和设备指引是否可直接进入。
- `InspectionLoadingActivity.EXTRA_NEXT_HOME_ACTIVITY`
  - 设备指引未初始化时由菜单写入，用于加载完成后回到设备指引首页。

## 11. 异常与降级分支

- 未初始化直进隐患识别或设备指引：
  - 路由到 `InspectionLoadingActivity`。
  - 开发重点检查 `InspectionSession.isInitialized`。
- 选中项越界：
  - 代码用 `coerceAtLeast` / `coerceAtMost` 限制首尾。
- 语音直达与当前选中项不一致：
  - 语音应直接触发目标项，不依赖当前高亮。
