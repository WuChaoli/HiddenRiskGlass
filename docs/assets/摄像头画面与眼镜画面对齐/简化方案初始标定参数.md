# 简化方案初始标定参数

> 状态：理论初值，尚未经过 Rokid Glass 真机校准。  
> 记录日期：2026-08-18。

## 目标

第一阶段将摄像头预览渲染到眼镜屏幕，并通过中心裁剪、平移和缩放，使预览画面与透过镜片看到的现实画面基本重叠。后续标注层复用同一坐标变换，实现检测框、文字和标记与现实目标的近似对齐。

## 输入参数与假设

| 项目 | 相机 | 屏幕 |
|---|---:|---:|
| 分辨率 | 3024 × 4032 px | 480 × 640 px |
| 对角分辨率 | 5040 px | 800 px |
| 对角视场角 | 109° | 30° |

当前计算基于以下假设：

- 相机和屏幕均使用竖屏 3:4 坐标系；
- 相机光轴与屏幕视觉中心一致，中心额外平移量暂定为 `(0, 0)`；
- 对角视场角采用无畸变的透视投影模型；
- 暂不考虑相机与人眼之间的物理偏移、目标深度、视差、镜头畸变和光学畸变；
- Android 实际预览帧未被 Camera 管线额外裁剪、旋转或缩放。

## 推导结果

根据对角视场角和 3:4 画幅换算：

| 参数 | 相机 | 屏幕 |
|---|---:|---:|
| 水平视场角 | 约 80.139° | 约 18.267° |
| 垂直视场角 | 约 96.559° | 约 24.198° |
| 等效像素焦距 | 约 1797.499 px | 约 1492.820 px |

相机坐标到屏幕坐标的理论缩放系数为：

```text
scaleX = 0.830499
scaleY = 0.830499
offsetX = 0
offsetY = 0
```

相机与屏幕中心分别为：

```text
cameraCenter = (1512, 2016)
screenCenter = (240, 320)
```

坐标转换公式：

```text
screenX = 240 + (cameraX - 1512) × 0.830499 + offsetX
screenY = 320 + (cameraY - 2016) × 0.830499 + offsetY
```

展开为仿射形式：

```text
screenX = 0.830499 × cameraX - 1015.714
screenY = 0.830499 × cameraY - 1354.286
```

对应的二维齐次变换矩阵为：

```text
| 0.830499  0         -1015.714 |
| 0         0.830499  -1354.286 |
| 0         0          1        |
```

## 理论中心裁剪区域

屏幕的 30° 对角视野对应相机中央约 `577.966 × 770.621 px`，实现时可先近似为 `578 × 771 px`。

理论浮点裁剪边界：

```text
left   = 1223.017
top    = 1630.689
right  = 1800.983
bottom = 2401.310
```

实时预览优先通过纹理矩阵完成中心裁剪和缩放，避免为每一帧创建裁剪后的 Bitmap。

## 真机校准边界

以上参数只能作为首轮渲染的理论初值，不能视为最终标定结果。实现中必须保留 `scaleX`、`scaleY`、`offsetX` 和 `offsetY` 四个独立可调参数，用于修正：

- 设备标称 FOV 与实际有效 FOV 的差异；
- Camera 预览管线引入的旋转、裁剪或缩放；
- 光学显示中心与屏幕像素中心的偏差；
- 摄像头与佩戴者眼睛存在物理位移所产生的视差。

真机校准完成后，应在本文档追加实测参数、预览输出尺寸、设备/OTA 版本、测试距离和验证结果，并保留本节理论值作为计算基线。

## ADB 标定测试页

测试功能复用独立的 `RawCameraPreviewDebugActivity`，不接入正式业务导航。启动命令：

```powershell
adb shell am start -n `
  com.rokid.glesse/com.rokid.glass.hiddenrisk.RawCameraPreviewDebugActivity `
  --es mode alignment_calibration `
  --ef scale 0.830499 `
  --ei offsetX 0 `
  --ei offsetY 0 `
  --ef alpha 0.5 `
  --ei translationStep 2 `
  --ef scaleStep 0.005
```

真机操作：

| 输入 | 行为 |
|---|---|
| 单击 | 在水平平移、垂直平移和等比缩放之间循环 |
| 前滑/左滑 | 当前参数减小一个步长 |
| 后滑/右滑 | 当前参数增加一个步长 |
| 双击或返回 | 输出最终参数日志并退出测试页 |

页面默认不显示相机底图（`alpha = 0`），只显示识别框、label、中心十字线和屏幕边框；相机 Surface 仍在后台渲染并供在线识别截帧。需要重新观察对齐效果时，可通过 ADB 的 `--ef alpha` 临时恢复半透明底图。顶部显示当前控制项、缩放、平移、步长、透明度、实际 View/Surface 尺寸及纹理裁剪参数。

退出页面后可通过以下命令提取最终参数：

```powershell
adb logcat -d -v brief | Select-String "AlignmentCalibration result"
```

标定页使用的 `3024 × 4032 / 109°` 是传感器理论输入；真机日志中的 Surface 输出尺寸用于确认 SDK 相机管线是否引入了额外旋转或裁剪。
