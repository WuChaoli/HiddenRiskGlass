# 架构总览

当前 `glassdemo` 正式巡检主链可以概括为五层：

1. 页面层：`InspectionLoadingActivity`、`WifiQrScanActivity`、`EnterpriseQrScanActivity`、`EnterpriseInfoActivity`、`AiInspectionMenuActivity`、`AiInspectionActivity`、`DeviceGuideActivity`、`HazardRecordActivity`、`InspectionEndReportActivity`
2. 会话层：`InspectionSession`、`InspectionWorkflowSession`
3. 输入层：`UnifiedInputSession`
4. 相机 / 帧流层：`InspectionCameraCoordinator`、`RokidFrameSource`、`InspectionFrameCaptureService`
5. 识别链路层：本地 HiddenRisk、在线 `/ai/ar`、设备指引远端判定链路

## 分层职责

- 页面层负责状态呈现、输入映射和跳转控制
- 会话层负责页面间共享状态、来源标记和巡检累计结果
- 输入层负责把触控/语音统一映射为业务动作
- 相机 / 帧流层负责不同页面对共享帧流和预览的占用协调
- 识别链路层负责检测、详情获取、保存与上报

## 当前协作关系

- `InspectionLoadingActivity`
  - 负责权限检查、SDK 初始化、相机预热和正式主链分流
- `InspectionSession`
  - 负责识别页和设备指引页的初始化门槛、本地模型实例与帧流状态
- `InspectionWorkflowSession`
  - 负责 Wi-Fi 模式、企业上下文、分析结果、结束页缩略图和统计
- `UnifiedInputSession`
  - 统一注册触控、语音和可选头部动作
- `InspectionCameraCoordinator`
  - 负责不同页面对共享帧流的 acquire / release
- `AiArSseService`
  - 提供 `/ai/ar` 相关流式识别、详情分析和设备指引详情链路
- `LocalHazardPushService`
  - 提供隐患本地上传
- `InspectionBackgroundUploadQueue` + `InspectionBackgroundUploadService`
  - 提供结束巡检后台上报

## 附录页边界

- `UnifiedInputDebugActivity`
  - 仅用于统一输入验证
- `HiddenRiskProbeActivity`
  - 仅用于模型 / 探针页验证
- `LightshotActivity`、`HomeActivity`、`InspectionModeActivity`
  - 具有调试或历史入口价值，但不作为当前产品基线
