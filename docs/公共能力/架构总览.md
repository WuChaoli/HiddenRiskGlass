# 架构总览

当前 `glassdemo` 正式巡检主链可以概括为四层：

1. 页面层：`InspectionLoadingActivity`、`WifiQrScanActivity`、`EnterpriseQrScanActivity`、`EnterpriseInfoActivity`、`AiInspectionMenuActivity`、`AiInspectionActivity`、`DeviceGuideActivity`、`HazardRecordActivity`、`InspectionEndReportActivity`
2. 会话层：`InspectionSession`、`InspectionWorkflowSession`
3. 输入层：`UnifiedInputSession`
4. 识别链路层：本地 HiddenRisk、在线 `/ai/ar`、设备指引远端判定链路

## 分层职责

- 页面层负责状态呈现、输入映射和跳转控制
- 会话层负责页面间共享状态、来源标记和巡检累计结果
- 输入层负责把触控/语音统一映射为业务动作
- 识别链路层负责检测、详情获取、保存与上报

## 真相源原则

- 页面行为以各功能目录下的 `页面说明.md` 与 `页面跳转.md` 为准
- 跨功能约束以本目录文档为准
