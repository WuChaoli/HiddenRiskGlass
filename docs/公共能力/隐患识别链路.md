# 隐患识别链路

关联总架构：[architecture.md](../architecture.md)

## 组成

- 加载入口：`InspectionLoadingActivity`
- 页面主控：`AiInspectionActivity`
- 会话：`InspectionSession`
- 自动链路决策：`AutoHazardPipelineDecider`
- 工作流状态：`InspectionWorkflowSession`
- 结束巡检提交：`InspectionFinishService`

## 当前链路基线

- 默认采用 remote-first 自动决策
- 网络可用时优先远端
- 远端主链中，物品识别 lane 为必跑主线，默认 `500ms` 一帧，超时 `3000ms`，最多允许 5 个并发请求
- 场景识别 lane 走 `/ai/general`，设备指引走 `/ai/device`
- 物品识别返回“是”后，停止在线检测并复用命中帧进入深度分析链路
- 已启动的在线 lane 都直接 fresh capture，不等待本地 NCNN shared frame
- 在线详情展示阶段保留原始文字流，不在流结束后改写已展示内容；保存 / 上传链路继续使用解析后的 `ResolvedHazardContent`
- `ResolvedHazardContent` 进入保存 / 上传前，由 `LocalHazardUploadItemBuilder` 组装上传项：跳过空 `hidNum`，跳过 `hidLevel = 2` 的重大隐患，按 `hidNum` 去重，重复时保留首条
- 隐患保存（`pushHidDanger`）和结束巡检（`pushHidDangerEnd`）接口仅通过单主 URL 提交，通过 `InspectionRetryExecutor` 最多重试 4 次，不再有备用端点
- 网络不可用或远端连续失败达到阈值后，再进入本地 fallback 链路
- 本地模型不在 loading 页预加载，而是在需要 fallback 时再加载
- 隐患识别物品检测默认地址为 `http://183.147.142.133:10010/ai/auto`
- 深度分析默认地址为 `http://183.147.142.133:10010/ai/deep`
- SSE 结束事件兼容 `data=[DONE]`、`type=done data=["DONE"]` 和空 done payload

## 页面态边界

- 检测态：负责自动识别、手动分析、跨功能跳转、结束任务
- 结果态：负责展示识别内容、确认、保存、返回检测
