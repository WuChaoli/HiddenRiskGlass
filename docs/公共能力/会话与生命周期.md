# 会话与生命周期

关联总架构：[architecture.md](../architecture.md)

## 会话对象

### `InspectionSession`

- 负责 `AiInspectionActivity`、`DeviceGuideActivity` 等识别链路的初始化门槛
- 维护 HiddenRisk NCNN 实例、帧流状态、初始化状态
- `InspectionSession.isInitialized` 是功能页能否直进的重要门槛

### `InspectionWorkflowSession`

- 负责正式巡检主链的跨页上下文
- 承接 Wi-Fi 在线/离线模式、企业二维码上下文、企业对象信息、分析结果、结束页缩略图和统计
- 也是结束巡检页、后台上传和结果回填的单一会话真相源

## 生命周期约束

- `InspectionLoadingActivity` 负责开始一次巡检会话，并在初始化完成后调用 `InspectionSession.markInitialized()`
- 识别页与设备指引页若在 `isInitialized == false` 时被直接启动，应回退到 `InspectionLoadingActivity`
- 结束巡查时应通过 `InspectionWorkflowSession` 构建结束页数据，而不是从单页面内重复拼装

## 自动睡眠监测

- 当前公共自动睡眠只监听眼镜佩戴/摘下广播，不再使用陀螺仪静止、触控或语音输入作为睡眠状态触发源。
- 佩戴状态保持 `WAKING`；检测到摘下后立即进入 `SLEEP_WARNING` 并保持弹窗。
- 重新佩戴后立即进入 `WAKE`，3 秒后回到 `WAKING`，业务页再恢复相机和识别链路。

## 当前关键写入点

- Wi-Fi 连接成功：
  - `InspectionWorkflowSession.updateMode(connected = true)`
- 企业二维码解析成功：
  - `InspectionWorkflowSession.updateEnterpriseFromQr(...)`
- 企业对象信息接口成功：
  - `InspectionWorkflowSession.updateEnterpriseObjectInfo(...)`
- 隐患识别或隐患录入分析：
  - `recordCapture(...)`
  - `recordDetection(...)`
  - `recordAnalysis(...)`
- 本地保存隐患：
  - `recordSavedHazardAttempt(...)`
  - `updateSavedHazardAttemptOutcome(...)`
- 结束巡检：
  - `buildEndReportThumbnails()`
  - `buildEndReportHazardCount()`
  - `resetAll()`
