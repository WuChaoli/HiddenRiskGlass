# 会话与生命周期

## 会话对象

### `InspectionSession`

- 负责 `AiInspectionActivity`、`DeviceGuideActivity` 等识别链路的初始化门槛
- 维护 HiddenRisk NCNN 实例、帧流状态、初始化状态
- `InspectionSession.isInitialized` 是功能页能否直进的重要门槛

### `InspectionWorkflowSession`

- 负责正式巡检主链的跨页上下文
- 承接 Wi-Fi 在线/离线模式、企业二维码上下文、企业对象信息、分析结果、结束页缩略图和统计

## 生命周期约束

- `InspectionLoadingActivity` 负责开始一次巡检会话，并在初始化完成后调用 `InspectionSession.markInitialized()`
- 识别页与设备指引页若在 `isInitialized == false` 时被直接启动，应回退到 `InspectionLoadingActivity`
- 结束巡查时应通过 `InspectionWorkflowSession` 构建结束页数据，而不是从单页面内重复拼装
