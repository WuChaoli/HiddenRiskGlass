# 日志系统

关联实现：[AppFileLogger.kt](../../app/src/main/java/com/rokid/glass/utils/AppFileLogger.kt)

本地诊断日志落盘工具，默认只在 DEBUG 构建中启用，便于通过 adb 拉取现场日志。

## 初始化

在 `MyApplication.onCreate` 中初始化：

```kotlin
AppFileLogger.init(this, enabled = BuildConfig.DEBUG)
```

同时安装全局未捕获异常处理器，异常时会自动写入独立 crash 文件并 flush。

## 日志级别

| 方法 | 级别 | 说明 |
|------|------|------|
| `AppFileLogger.d(tag, msg)` | DEBUG | 调试日志 |
| `AppFileLogger.i(tag, msg)` | INFO | 信息日志 |
| `AppFileLogger.w(tag, msg)` | WARN | 警告日志 |
| `AppFileLogger.e(tag, msg, throwable?)` | ERROR | 错误日志 |

所有方法同时输出到 Android Logcat 和本地文件。

## 文件结构

```
<getExternalFilesDir>/logs/
├── app-2026-05-13.log        # 当天日志（按日期分片）
├── app-2026-05-13-1.log      # 滚动文件（单文件超过 2MB 自动滚动）
├── app-2026-05-12.log        # 历史日志
├── crash-2026-05-13-15-16-00.log  # 崩溃日志（按时分秒命名）
└── ...
```

- 日志目录：`Android/data/com.rokid.glesse/files/logs/`
- 单文件上限：**2MB**
- 保留数量：最多 **7 个** app 日志文件（按最后修改时间保留），超出的自动删除
- 日志格式：`yyyy-MM-dd HH:mm:ss.SSS 级别/标签 消息`

## 异步写入

所有文件写入在单线程后台执行（守护线程），不阻塞主线程和调用方。

## 已接入模块

- `MyApplication` — 应用级日志（退出清理、全局异常）
- `RokidFrameSource` — 相机帧流生命周期（启动、复用、关闭、重启、错误）
- `RokidFrameSource` / `RawCameraPreviewDebugActivity` — 共享相机诊断（NV21/Surface active、请求/实际配置、支持分辨率、恢复是否复用 helper）
- `AiArSseService` — SSE 在线识别请求生命周期（请求构建、连接建立、首帧、关闭、失败）
- `InspectionLoadingActivity` — SDK 状态变更
- `LocalHazardPushService` — 本地隐患上报请求（主链路/备用链路、失败分类、响应）
- `OnlineHazardDetectionService` — 在线并发隐患检测
- `AiInspectionActivity` — 自动在线识别、状态切换、fallback、详情失败、上传收口
- `WifiQrScanActivity` — 扫码、配网、验证、退出收口

## adb 拉取日志

```bash
# 拉取完整日志目录
adb pull /sdcard/Android/data/com.rokid.glesse/files/logs/ ./logs/

# 查看设备端日志文件，确认当天文件名
adb shell ls -lt /sdcard/Android/data/com.rokid.glesse/files/logs/

# 实时查看当天日志（设备 shell 支持 date 时可用）
adb shell tail -f /sdcard/Android/data/com.rokid.glesse/files/logs/app-$(date +%F).log
```

若设备 shell 不支持 `date +%F`，先用 `ls -lt` 查出当天 `app-YYYY-MM-DD.log` 文件名，再替换到 `tail -f` 命令中。
