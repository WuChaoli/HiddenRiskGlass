# 隐患识别页面跳转

- `InspectionLoadingActivity` 可进入：
  - `WifiQrScanActivity`
  - `EnterpriseQrScanActivity`
  - `AiInspectionActivity`
  - `DeviceGuideActivity`
- `AiInspectionActivity` 在检测态支持跳转到：
  - `DeviceGuideActivity`
  - `HazardRecordActivity`
  - `InspectionEndReportActivity`
- `AiInspectionActivity` 在未初始化时应回退到 `InspectionLoadingActivity`
