# 主菜单页面跳转

- “隐患分析”：
  - `InspectionSession.isInitialized == true` 时进入 `AiInspectionActivity`
  - 否则进入 `InspectionLoadingActivity`
- “设备指引”：
  - `InspectionSession.isInitialized == true` 时进入 `DeviceGuideActivity`
  - 否则进入 `InspectionLoadingActivity`，并带 `EXTRA_NEXT_HOME_ACTIVITY`
- “隐患录入”：直接进入 `HazardRecordActivity`
